Ce que Uny vous apporte

📣 Vos offres envoyées à tous les étudiants

Chaque nouvelle offre part en notification sur le téléphone de tous les étudiants Uny. Pas de publicité à payer.

⚡ Offres flash pour vos heures creuses

« -20 % ce midi, 30 places » : une promo limitée dans le temps et en quantité, annoncée tout de suite. Idéal pour remplir une salle.

🎁 Carte de fidélité numérique

Un tampon à chaque passage, la récompense de votre choix au palier (ex. 5 repas = le 6e offert). Récompensez aussi à la main vos meilleurs clients.

📊 Vos résultats chaque semaine

Vues, codes obtenus, clients venus, ventes réalisées : un bilan envoyé chaque lundi pour mesurer ce que Uny vous rapporte.

✅ Uniquement de vrais étudiants

Chaque carte est vérifiée. Au comptoir, scannez le QR code ou le code promo : vous voyez la photo et le statut en direct.

🟠 Paiement Orange Money direct

Ajoutez votre code marchand : l'étudiant paie depuis son téléphone, directement sur votre compte. Uny ne touche pas à l'argent.

1
Inscrivez-vous sur unyafrica.com/partenaires (2 minutes).
2
Publiez une offre simple et chiffrée : « -15 % », « boisson offerte »…
3
Scannez la carte ou le code au comptoir : le client est compté, sa fidélité avance.
