# Guide du magasinier — application « Stocks »

**Votre travail : ce qui entre, ce qui sort, ce qui est prêt pour les clients.**

En haut de l'écran **Vue d'ensemble** :
- **À faire aujourd'hui** : vos 4 gestes du jour.
- **En attente de vous** : ce qui vous attend (commande à préparer, article qui manque…). Touchez une ligne pour agir.
- **Ce qui vient de se passer** : les dernières entrées et sorties.

## 1. Préparer une commande
1. **Préparer une commande** → choisissez la commande → **Préparer les colis**.
2. Pour chaque produit, écrivez les **colis préparés** (vous pouvez en préparer moins si le stock manque), puis **Enregistrer**.
3. **Les colis sont prêts : valider la sortie du stock** → relisez → **Oui, valider**.
Le reste de la commande attend. La comptabilité voit tout de suite ce qu'elle peut facturer.

Dans **Commandes à préparer**, le tableau du haut montre pour chaque produit : **en stock**, **réservé** pour les commandes, **disponible**.

## 2. Réceptionner
- **Réceptions attendues** (sur la vue d'ensemble) : les conteneurs en route et leur date d'arrivée.
- À l'arrivée : **Réceptionner** → choisissez le conteneur → numéro et poids de chaque bobine → **Réceptionner la bobine**.

## 3. Sortie ou entrée
**Sortie ou entrée** → choisissez le grand bouton (Sortie pour l'usine, Autre sortie, Jeté, Correction…) → article, quantité → enregistrer.
Une erreur ne s'efface pas : on fait le mouvement inverse.

## 4. Compter le stock
**Compter le stock** → **Commencer un comptage** → écrivez ce que vous comptez.
- Pas fini ? **Enregistrer et continuer plus tard**.
- Fini : **Valider**. Les cases laissées vides gardent le stock de l'ERP.
